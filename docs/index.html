    What you get

    Stays on the machine

    Audio is transcribed by Whisper locally. There is no account and no cloud API.

    Types into the front app

    macOS, Windows and Linux. A menu-bar or tray app, not a web form.

    Yours to keep

    MIT licensed. Models download in the app. Corrections are a plain list you edit.

    macOS: open the app, then finish the setup panel. Rustle copies itself into Applications and restarts once Input Monitoring and Accessibility are on. Downloads are not Apple-notarised yet, so System Settings may still show Open Anyway the first time. Windows may warn that the installer is unsigned. Linux paste needs xdotool, wtype or ydotool.

    From source

    Rust, cmake and Node. Packages stay in the repo. Nothing needs to go in /Applications.
