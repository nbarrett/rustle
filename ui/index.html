This is the dictation to use instead of the phone’s. Turn off Apple Dictation (Settings → General → Keyboard → Enable Dictation). Add the Rustle keyboard: Settings → General → Keyboard → Keyboards → Add New Keyboard → Rustle, then Allow Full Access. In WhatsApp or Mail, switch to that keyboard and tap the mic. Talk there; tap again when you are done. Whisper types the English into the field.
